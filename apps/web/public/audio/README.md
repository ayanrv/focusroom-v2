# FocusRoom audio assets

Curated rooms use a hybrid model: some layers are generated in the browser and the rest are ordinary audio files.

Add your own licensed/owned files at these exact paths:

- public/audio/rain-city/traffic.mp3
- public/audio/rain-city/city-life.mp3
- public/audio/night-train/lofi.mp3
- public/audio/orbital-lab/cosmos.mp3
- public/audio/cozy-cafe/crowd.mp3
- public/audio/cozy-cafe/coffee-bar.mp3
- public/audio/cozy-cafe/jazz-vinyl.mp3

Already procedural:
- Rain City: rain + occasional thunder
- Night Train: rails
- Night Train: wind
- Orbital Lab: ventilation
- Orbital Lab: systems

Suggested file characteristics:
- long seamless or near-seamless ambience
- stereo
- no aggressive normalization
- avoid obvious intros/outros
- preferably 5+ minutes for ambience and substantially longer for music
- only use audio you have permission to include in the app

Custom Rooms are intentionally separate from these curated rooms. They should later accept their own media source, visuals, timer and goal without inheriting a Rain City / Night Train / Orbital Lab / Cozy Cafe ambience preset.
